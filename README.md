## Installation
```
cd deinProjektordner
git clone https://github.com/jannikhug/deweb_ai_agent.git
cd deweb_ai_agent
```

## Erstelle .env-Datei
Linux/Mac Terminal: 
```
cp .env.sample .env
```
Windows Terminal: 
```
copy .env.sample .env
```

Öffne ``.env`` in deinem Code-Editor und füge deinen Github-Copilot API-Key und OpenAI API-Key (oauth_token) hinzu.



## Server starten
```
bun run server.js
```
